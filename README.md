---

### What Blue is

- **Orthogonal persistence.** Data outlives the program, with no ORM, schema or save call.
- **Actors in the language.** Actors have their own syntax, not a library API.
- **Self-healing clusters.** Nodes discover each other and recover on their own.
- **Clean ML-family syntax.** Typed, concise and readable, with a deliberately lean core.

Blue draws on ideas from PS-Algol, Standard ML, Erlang, Oberon and Smalltalk, and runs on the JVM.

### Status

Blue is in active development ahead of a public preview in **spring 2027**. The compiler, docs and tutorials are being prepared now.
